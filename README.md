# LOKA — инженерные решения, работы и деньги

Версия 0.5.1 · 1 ноября 2026 года.

[Открыть работы и деньги по общей ссылке](https://netkiller54.github.io/loka-engineering-catalog/) · [Открыть Гант](https://netkiller54.github.io/loka-engineering-catalog/?v=0.5.1#gantt)

Автономная демонстрация: пять примеров каталога, карта 78 областей, модель C-03 / C03-TUBE-01 и низкий облёт к насосам P-101 длительностью 2 мин 30 с. Уже розданная общая ссылка сразу открывает «Работы и деньги», добавляя #finance без лишнего шага в истории. Параметры URL сохраняются. Явный #gantt открывает график. Модель и ручной запуск маршрута доступны через «Весь завод» → «Начать облёт / повторить». Кнопки «Работы и деньги» и «Гант и сроки» доступны в шапке, в том числе во время облёта.

Вкладка «Гант и ресурсы» связывает оба насоса с восемью общими пакетами CW и тремя сохранёнными результатами планирования. Версия 0.5 добавляет финансовое сравнение четырёх наборов последствий, локальный Гант монтажа/ожидания/исправления, разницу по каждой работе, недельный денежный календарь, явные редактируемые допущения и учебный журнал отказа/повторной приёмки. Новые расходы считаются в браузере, общий график завода не пересчитывается. Восемь пакетов CW считаются один раз для двух насосов; индивидуальная стоимость насосов не выделена.

При исходных условиях «Все последствия»: затраты +4 220 000 ₽, расчётная прибыль -4 220 000 ₽, потребность в финансировании 836 538 400 → 959 198 400 ₽. Сдвиг срока сам по себе не начисляет дополнительные расходы. Финансовые условия и цена договора учебные; это не реальные договоры, платежи или утверждённый бюджет завода. Полное описание целевой системы и протокол допущений открываются внутри приложения. Аудиозапись и её расшифровка в публичный файл не включены.

Изменения узла, заметки, экземпляры, выбранный график, финансовые условия и учебная история сохраняются вручную через «Сохранить сценарий» в JSON; «Открыть сценарий» восстанавливает их. Финансовый JSON и CSV — отдельные отчёты, а не файлы восстановления.

Для 3D нужен WebGL. Первый HTML около 17 МБ, распаковка модели может занять несколько секунд. Все ресурсы встроены, зависимости во время просмотра не скачиваются. JavaScript приложения, Three.js r180 и OrbitControls минимизирован esbuild 0.25.12; лицензия MIT сохранена, source maps не выпускаются. Минимизация не обеспечивает секретность кода или данных, переданных браузеру.

Геометрия и исходный ресурсный план синтетические и содержат допущения. Инженерная пригодность не подтверждена. Права, юридические подписи, фактический учёт и серверная совместная работа описаны как следующий этап. `index.html` — готовая автономная сборка; GitHub Pages публикует корень ветки `main`, `.nojekyll` отключает Jekyll.
